# 史前天地：原生岛屿快照

2026-10-18 保存的可运行实验版本，以固定 Tidewater 原生 WebGPU/WGSL 应用为渲染底座，接入博物馆自己的岛屿、动物和参观体验。此目录属于独立实验分支，尚未并入正式网站。代码、运行资产、来源锁和第三方许可随分支保存；本地巡查记录和研究归档单独保留。

## 运行

在仓库根目录安装锁定依赖，再运行此目录的独立入口。运行需要支持 WebGPU 的桌面浏览器；首次加载会编译着色器。

```sh
npm ci
node prototypes/island-tidewater/build.mjs
node node_modules/vite/bin/vite.js --config prototypes/island-tidewater/vite.config.mjs --port 4402
```

`http://127.0.0.1:4402/island/` 为整岛总图，`/creek/` 为连续 3D 世界。区域菜单可进入九类展区；WASD 步行/游泳，F 切换飞行，E/空格上升、Q/C下降，Shift 六倍加速。飞行有12/48/160/500米每秒四档。Esc暂停，点击继续；导览面板可以收起。自然声在点击开启后才播放，包含海浪与定位鸟鸣，无麦克风采集。

- 溪谷与混交林、西岸岩湾、古杉巨木林、山间长湖、东部疏林高草甸、低地湿地、寒凉高地、背风旱谷、东岸浅海属于同一座岛，可连续走动或飞行。
- 湖面、水下、主河、支流、湿地和源头共享实际水位；海面保留原生FFT、冲岸、水下和空气透视。
- 既有22米迷惑龙和8.5米三角龙在连续样板的干岸林地展示，原始动物模型未变；原生海湾对照入口仍使用原位。
- 光照可选择午间、晨间、傍晚或区域推荐时段，使用太阳与环境照明，不给区域套颜色滤镜。

## 西岸连续样板

`/creek/?place=sample-overview` 进入约1105米的有限制作样板，导览菜单有岩隙细泉、浅池、巨木根盘、倒木潭、下游溪潭、河口与水下等固定观察点。泉源保持细沟，上中游主要溪潭湿宽约7–16米、深1.4–2.3米，下游主潭湿宽约22米、深2.5米，水道逐段展宽并加深；河口接入弧形宽沙滩与浅海砂槽。`/creek/?place=sample-mouth` 从步行高度看河口，`/creek/?place=sample-coral` 进入浅海硬底的珊瑚与贝壳观察点。样板采用独立可重建地形层，细泉为0.25米、流域为1米采样；CPU碰撞、GPU地表、水域和生境共用字段。“本机位原版对照”在同一机位、视场与时刻切回冻结地形，返回后恢复样板。

河口后岸以2米采样的局部疏密图组织低草、草丛与裸露地表，几何草和地面共享同一字段。偏黄的茅草底、绿色地被与林下土色连续交接；实际坡度让陡面退出高草，湿岸仍保留沿水植被。该分布属于场景美术调整，性能记录另保留原覆盖对照。

这是第一轮制作候选。泉口湿隙、河岸形态、森林分层与树冠时序仍需改进，尚未通过整体自然度验收，不扩展到全岛。树高与网格胸径可量尺；报告中的冠幅仅是模板名义跨度。泉口几何由本馆在Blender中制作，溪流声使用有署名的NPS公共领域现代录音。真实DEM、独立测深及基准资料用于研究；当前设计坐标未导入这些测绘数据，不称为实地或史前精确重建。

样板从馆内36项主馆藏选出6种代表。陆地有迷惑龙、三角龙、水龙兽与副栉龙；海岸上空有无齿翼龙，外缘海槽有鱼龙。新接入的4种保留源骨骼与局部动作，副栉龙按源短步动作以约0.18米每秒觅食，游客靠近时让行；鱼龙按全身动画包络选择可通行的海槽。翼龙单独计数。连续样板菜单也可进入苏铁蕨丛、溪岸水蕨、浅海海草与仙掌藻、三趾旧步迹。足迹是贴合实际坡面的浅浮雕，未改变CPU地形碰撞，也不代表当前短步动作逐次踩出的新印。

静态低模动物通过本馆适配器补功能关节。两种翼龙有肩、肘、腕与翼指，翼膜和支撑指共用权重；巨脉蜻蜓有四翼、腹节及收足动作；Eryon 的十条步足分别分节、错相，并带动足端钳。Aeger 的步足、颚足、腹泳足与触须分开绑定，源材质不再当作器官分类。成对鱼鳍绕真实几何根部摆动，奇虾的侧瓣逐对错相；批量绘制保留当前和前一帧的姿态及法线。原始 GLB 字节不变。

馆藏动作另外修正鱼龙四个鳍根，并平滑鱼龙和无齿翼龙的旋转曲线；副栉龙保留原步幅，复用源 Idle 的颈尾动作；水龙兽增加轻微观察动作。这些是展示动画，化石不能给出这里采用的精确频率与幅度。近景录像菜单新增翼膜、甲壳类步足和昆虫停栖的跟随机位，录像与性能采样仍分开。

## 数据与性能组织

原博物馆世界基于本仓库的岛屿探索与飞行场景，场景坐标仅减去 `[-2000,-650]`。已烘焙运行数据包含在本目录，不需要相邻检出即可运行。地貌适配、数据导出和运行时床面起伏均有明确版本。

- 32km/16m全局地形包住原20.48km世界；三块8km/4m区域、1km/1m原溪谷、两块256m/0.5m泉源共同组成一张连续地表。
- 高度与法线用原生纹理数组保存多个分辨率，保持采样绑定数量；CPU碰撞、草根、GPU地表和水深读取同一组合规则。构建逐项校验原始数据与资产锁。
- 地形CDLOD等级随世界大小推导，64网格、范围系数3；海面17级覆盖300km相机视距，避免高空看到旧有限网格边缘。
- 草丛保留原生35/12/2三角形真LOD，按世界固定湿度、林缘和开地分配高低层。木贼形、蕨形、低地被与高草是不同形态；现代花朵关闭。
- 普通树、扇叶、矮针林和40–60m巨木使用不同近场池。图集保存原RGB、八面体叶法线、叶片语义与冠内遮蔽。巨木约190m交接，普通树约65m，互补交接带加宽；远处没有随相机删树。全岛树干碰撞用空间索引查询附近树。
- 连续样板使用 Lowpoly Vault 的 40 种鱼、底栖动物、珊瑚、贝壳、海绵、昆虫与翼龙模型；运行时给适用的动物加入摆尾、游鳍、觅食、逃逸及振翅。溪潭、河口、浅海按淡咸水与水深分配，珊瑚和贝壳只出现在海洋硬底或邻近沙地；其中10种壳形作为静物展示，17种珊瑚组成分离礁丛。不同年代的史前生物可共处于这座想象岛屿，翼龙单独计数。其他海岸保留原生环境鱼与鸟。海水/淡水浮游颗粒分别处理水深、涌浪和慢漂移。
- 小物件、光照、水下、阴影、运动向量、折射、SMAA→TAAU保持一条渲染链；不导入旧WebGL渲染或历史滤波补丁。

需要重新导出地形时，向工具传入包含原始岛屿探索和飞行场景的源仓库目录；当前分支已保存这些来源及导出的运行数据。以下命令从仓库根目录执行，最后一个参数 `.` 表示当前仓库：

```sh
node prototypes/island-tidewater/tools/prepare-creek.mjs .
node prototypes/island-tidewater/tools/prepare-coast.mjs .
node prototypes/island-tidewater/tools/prepare-watershed.mjs .
node prototypes/island-tidewater/tools/prepare-island.mjs .
node prototypes/island-tidewater/tools/prepare-island-plan.mjs .
```

运行时修正记录在 `IslandWaterField.js` / `WholeIslandData.js` 等本馆适配器中；导出源文件保持不变。构建先验证430个上游文件、动物转换、原始材质、地图、溪谷、海岸、主流域和全岛数据的SHA-256，再生成源码哈希。

## 本地证据与验证

开发只运行受影响区域的有头定向检查；冻结后运行一次完整相关回归，失败记录保留，修复后只重验影响项。不创建事后单元测试，不启动headless浏览器。

诊断面板可切换水体表示、光学分项、树冠表示/光照分项和旧抽稀。正常观察、12秒录像、10/20秒声音记录和独立性能采样分开进行。独立计时先预热3秒，再采8秒；期间不截图、录屏或像素读回。GPU时间戳取实际compute/render区间首尾，不包含全部上传、浏览器合成和实际显示；Metal分项不可简单相加。60FPS是提交目标，短测不能证明长期稳定或实际呈现60FPS。

现场截图快捷键 P 会一并复制机位和实际抗锯齿状态。Vite 本地保存端点仅接受同源 localhost 请求；正式静态构建不提供该写入端点。用户主动保存的画面和定位文字留在本机。

## 已知限制

- 本版本完成了一轮泉口、溪床、河海接续与树冠稳定性修正，尚未完成全岛最终美术验收。
- 植被细边仍有时序变化；局部溪岸、湖岸和沙纹有规则化特征。
- Aeger 已按身体移动速度推进分足步态，并根据尺寸和坡面贴床，但尚无世界坐标中的支撑足锁定；极近处仍可能滑足。新增功能骨架和关节幅度属于展示推断，尚未构成完整动物运动或水动力求解。
- 2026-10-29 本地同机位短测在2320×1329、scale1、SMAA+TAA和全部环境系统下，水下37.00→52.87FPS，上游溪流31.37→38.62FPS；对照关闭新疏密图，草块和三角数保持一致。测试各采8秒，稳定60FPS仍未通过；无齿翼龙翼膜闪烁还需取得可复现机位。
- 稳定60FPS目标未达成。河口在本机2320×1329、SMAA→TAA、完整画质与全部环境系统下，同一固定步行机位修正前8秒短测为40.24FPS、GPU中位22.61ms；修正后的两次短测为42.49与38.12FPS、GPU中位21.30与23.53ms。短测存在波动，不能据此断言性能提升或长期热稳定；完整计时记录保存在本地私有验收资料。
- 西岸有限连续样板已开始制作，需通过自然度与性能验收后再逐区拓展。

## 来源、科学表达和边界

上游固定 `4811ba48d795197de5621985f404e765c0b7c0ef`，完整430个追踪文件保持原样，MIT与原作者DRG Software Solutions LLC署名保留。`reference/` 是原生场景对照，`museum/` 是原生海湾的动物兼容性对照；二者不是同一博物馆场景的因果性能基线。许可见 `NOTICE.md`，录音逐项来源见 `vendor/tidewater/public/audio/CREDITS.md`。

这些是生态地貌展区与美术外形候选，岛屿允许不同时代的史前生物共处。巨木的设计不依据“整个恐龙时代均高氧”的假设。动物仍按淡水、海水与空中生境安置；其他海岸的现代鸟形与CC0鸟鸣仍是环境示意。具体古植物、动物物种、气候年代仍需随内容接入逐项核对。内陆水面反射仍受屏幕/有限高度场影响，独立河流焦散和海洋玩法尚未定义，移动端与长期热稳定性需另测。
