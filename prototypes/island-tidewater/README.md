# 史前天地 · 整岛漫游

九片地貌相连的桌面 WebGPU 岛屿。游客可以从总图找一只动物，落到人的眼高沿河岸步行，也可以飞越山脊或潜入大陆架。西岸保留约 1.1 公里的连续样品路线。岛上另有五条近景地貌路线，以及来自博物馆主目录的 45 种动物。每个观察点说明动物的地质年代与栖息环境。

本目录属于 `feat/island-continuous-sample` 独立分支。引擎、模型转换、运行资产和署名随分支保存。

## 运行

在仓库根目录安装锁定依赖，再运行此目录的独立入口。运行需要支持 WebGPU 的桌面浏览器；首次加载会编译着色器。

```sh
npm ci
node prototypes/island-tidewater/build.mjs
node node_modules/vite/bin/vite.js preview --config prototypes/island-tidewater/vite.config.mjs --host 127.0.0.1 --port 4402 --strictPort
```

打开整岛总图可选动物或展区，也可以直接从西岸样板河口、南部主河口岸边或俯瞰、冰碛湖畔或旱谷层崖开始。点击三维场景后用鼠标环顾，WASD 移动，F 在步行与飞行间切换，Esc 释放鼠标。飞行支持四档速度。点击「开启自然声」后，浪、风、鸟鸣和淡水声源随地点与距离变化。 [整岛总图](http://127.0.0.1:4402/island/) · [西岸样板河口](http://127.0.0.1:4402/creek/?place=sample-mouth) · [南部主河口岸边](http://127.0.0.1:4402/creek/?place=estuary) · [南部主河口俯瞰](http://127.0.0.1:4402/creek/?place=main-estuary-overlook) · [冰碛湖畔](http://127.0.0.1:4402/creek/?place=tarn-moraine) · [旱谷层崖](http://127.0.0.1:4402/creek/?place=dry-escarpment)

- 总图和入岛缩略图来自游览时使用的同一套地形与水域。打开总图先读取 123 KiB 的地形图，切换生态图层时再读取生态图。溪谷、岩湾、巨木林、长湖、草甸、湿地、高地、旱谷和东部浅海均可连续穿行。
- 45 种馆藏各有可直达的观察点。场内可点「找动物」或按 G，用中文名、英文名或生境查找动物，也可筛选附近的陆地、空中、淡水、海水和水底动物。锁定后，小地图标出目标，中文提示更新方向、距离和适用的高度或深度。活体尚未加载时显示栖息地位置。动物游远时，「看向动物」可转回它当前所在的方向。年代和模型署名可在导览中查看。
- 内陆支流弯道、长湖砾岸、冰碛小湖、旱谷层崖与湿地浅沟有独立的地形、岸坡、水深与生境。陆地观察点按人的视高选址，游泳与潜水跟随当地水位，陡坡上保留可绕行的方向。
- 馆藏分布在 15 组生境中，包括陆地 22 种、空中 8 种、海水 13 种、淡水 1 种及海底 1 种。各时代的生境共同构成一座博物馆岛。模型保留可用的源骨架和形变。陆生馆藏使用在 Blender 中制作的步态，并根据实际路面调整落脚。21 个大型陆生模型的躯干有依照网格断面设置的碰撞体，部分动物会朝向靠近的游客。观察点列出模型的作者和许可。
- 光照可选择午间、晨间、傍晚或区域推荐时段，使用相同的太阳和环境照明。

## 西岸连续样板

`/creek/?place=sample-overview` 进入约1105米的有限制作样板，导览菜单有岩隙细泉、浅池、巨木根盘、倒木潭、下游溪潭、河口与水下等固定观察点。泉源保持细沟，上中游主要溪潭湿宽约7–16米、深1.4–2.3米，下游主潭湿宽约22米、深2.5米，水道逐段展宽并加深；河口接入弧形宽沙滩与浅海砂槽。`/creek/?place=sample-mouth` 从步行高度看河口，`/creek/?place=sample-coral` 进入浅海硬底的珊瑚与贝壳观察点。样板采用独立可重建地形层，细泉为0.25米、流域为1米采样；CPU碰撞、GPU地表、水域和生境共用字段。“本机位原版对照”在同一机位、视场与时刻切回冻结地形，返回后恢复样板。

河口后岸以2米采样的局部疏密图组织低草、草丛与裸露地表，几何草和地面共享同一字段。偏黄的茅草底、绿色地被与林下土色连续交接；实际坡度让陡面退出高草，湿岸仍保留沿水植被。该分布属于场景美术调整，性能记录另保留原覆盖对照。

泉口几何由本馆在 Blender 中制作，溪流声使用有署名的 NPS 公共领域现代录音。真实 DEM、独立测深及基准资料用于研究。岛上地形在博物馆坐标系内创作。树高和树干胸径可以实测，树冠跨度是模板的名义尺寸。

西岸样板保留 6 个馆藏观察点。陆地有迷惑龙、三角龙、水龙兽与副栉龙。海岸上空有无齿翼龙，外缘海槽有鱼龙。水龙兽、副栉龙、无齿翼龙与鱼龙保留源骨骼和局部动作。副栉龙在缓岸的觅食路线设定速度为每秒 0.50 米，接近路线端点及游客时减速。鱼龙按全身动画包络选择可通行的海槽。翼龙单独计数。连续样板菜单也可进入苏铁蕨丛、溪岸水蕨、浅海海草与仙掌藻、三趾旧步迹。足迹是贴合实际坡面的浅浮雕，未改变 CPU 地形碰撞，也不代表当前短步动作逐次踩出的新印。

西岸上空的无齿翼龙使用馆藏原件和原飞行动作。环境鸟虫与鱼群只选取经本岛复看造型和动作的 Vault 修复版本。接入时对照来源文件，在侧、前和俯视角检查体形、关节和贴图，再用游览距离检查游动或振翅时的轮廓。适合辨认的壳体和珊瑚用于海底静态布置。

馆藏鱼龙使用四个独立鳍根和摆尾动作。近景录像菜单可跟拍无齿翼龙的翼膜、游动的鱼龙及陆生动物。馆藏动作的节奏和幅度是展示用的复原。

## 数据与性能组织

原博物馆世界基于本仓库的岛屿探索与飞行场景，场景坐标仅减去 `[-2000,-650]`。已烘焙运行数据包含在本目录，不需要相邻检出即可运行。地貌适配、数据导出和运行时床面起伏均有明确版本。

- 32km/16m全局地形包住原20.48km世界；三块8km/4m区域、1km/1m原溪谷、两块256m/0.5m泉源共同组成一张连续地表。
- 高度与法线用原生纹理数组保存多个分辨率，保持采样绑定数量；CPU碰撞、草根、GPU地表和水深读取同一组合规则。构建逐项校验原始数据与资产锁。
- 地形CDLOD等级随世界大小推导，64网格、范围系数3；海面17级覆盖300km相机视距，避免高空看到旧有限网格边缘。
- 草丛保留原生35/12/2三角形真LOD，按世界固定湿度、林缘和开地分配高低层。木贼形、蕨形、低地被与高草是不同形态；现代花朵关闭。
- 普通树、扇叶、矮针林和40–60m巨木使用不同近场池。图集保存原RGB、八面体叶法线、叶片语义与冠内遮蔽。巨木约190m交接，普通树约65m，互补交接带加宽；远处没有随相机删树。全岛树干碰撞用空间索引查询附近树。
- 淡水鱼群沿溪潭和湖岸活动，海鱼分布于河口与大陆架。珊瑚、壳体与海绵按水深和底质放置，沙槽留出供鱼群通过的空间。海洋和淡水浮游颗粒分别处理水深、涌浪和慢漂移。
- 小物件、光照、水下、阴影、运动向量、折射、SMAA→TAAU保持一条渲染链；不导入旧WebGL渲染或历史滤波补丁。

- 45 个馆藏模型独立压缩，合计约 112.8 MB。主要体表的底色与法线贴图最长边上限为 1024 像素，其余贴图为 512 像素。馆藏按游客位置排队，同时最多加载 2 个实例，近场最多驻留 16 个个体、8 个物种，估算 GPU 预算为 128 MiB。同种个体共享几何和贴图，分别保留各自的姿态。快速切区会取消失去优先级的请求并释放旧模型。环境鱼群、鸟虫和礁区素材也按接近程度加载。
- 18 份地形数据采用无损差分与压缩传输，传输体积从 124.3 MB 减到 38.2 MB。地表与水面仍从共用的高程和水位取样。远离海岸时跳过局部碎浪和岸边声源运算。
- 自动画质按实际 GPU 提交是否来得及调整三维分辨率。大窗口先降低场景内部像素数；如果时间重建、辉光和最后合成仍造成持续掉帧，才缩小三维画布，导览文字保持窗口分辨率。负载回落后逐步恢复清晰度。选择固定完整画质可恢复原始画布，双倍像素对照保留指定密度。开阔海水中，视点同时低于水面 2.75 米并离海床超过 2 米时，自动档可再降低内部绘制密度；贴近底栖动物时恢复近景精度。
- 生态观察点按水深、坡度和底质布置。来自 Vault 的层理砂岩、冰川漂砾、苏铁与水蕨等素材按地点加载，构建时核对模型清单与文件哈希。来源、许可与改动见 `NOTICE.md`。

需要重新导出地形时，向工具传入包含原始岛屿探索和飞行场景的源仓库目录；当前分支已保存这些来源及导出的运行数据。以下命令从仓库根目录执行，最后一个参数 `.` 表示当前仓库：

```sh
node prototypes/island-tidewater/tools/prepare-creek.mjs .
node prototypes/island-tidewater/tools/prepare-coast.mjs .
node prototypes/island-tidewater/tools/prepare-watershed.mjs .
node prototypes/island-tidewater/tools/prepare-island.mjs .
```

运行时修正记录在 `IslandWaterField.js` / `WholeIslandData.js` 等本馆适配器中。运行 `node prototypes/island-tidewater/tools/prepare-island-plan.mjs`，可用现有运行数据按 40 米间隔重采样岛屿地图，同时更新入岛缩略图及校验记录。构建先验证430个上游文件、动物转换、原始材质、地图、溪谷、海岸、主流域和全岛数据的 SHA-256，再生成源码哈希。区域地貌可独立运行 `node prototypes/island-tidewater/tools/verify-regional-landforms.mjs`，检查命名步道及远离观察点的地形断面。

## 本地证据与验证

开发只运行受影响区域的有头定向检查；冻结后运行一次完整相关回归，失败记录保留，修复后只重验影响项。不创建事后单元测试，不启动headless浏览器。

诊断面板可切换水体表示、光学分项、树冠表示/光照分项和旧抽稀。正常观察、12秒录像、10/20秒声音记录和独立性能采样分开进行。独立计时先预热3秒，再采8秒；期间不截图、录屏或像素读回。GPU时间戳取实际compute/render区间首尾，不包含全部上传、浏览器合成和实际显示；Metal分项不可简单相加。60FPS是提交目标，短测不能证明长期稳定或实际呈现60FPS。

现场截图快捷键 P 会一并复制机位和实际抗锯齿状态。Vite 本地保存端点仅接受同源 localhost 请求；正式静态构建不提供该写入端点。用户主动保存的画面和定位文字留在本机。

## 体验边界

- 默认画质会按持续帧负载调整内部渲染分辨率。输出分辨率、透明水面、可见树冠和镜头运动都会影响实际帧率。可在诊断面板锁定完整分辨率，与相同机位的自适应模式分别计时。
- Aeger 的步态按身体速度、尺寸和坡面推进。其支撑足没有世界坐标锁定，极近处仍可能滑足。动物的警觉距离、关节摆幅和运动轨迹均为展示推断。
- 植被细边在运动中仍有时序变化，水面反射受屏幕和有限高度场影响。首次访问需要下载地形并编译 WebGPU 管线。

## 来源、科学表达和边界

上游固定 `4811ba48d795197de5621985f404e765c0b7c0ef`，完整430个追踪文件保持原样，MIT与原作者DRG Software Solutions LLC署名保留。`reference/` 是原生场景对照，`museum/` 是原生海湾的动物兼容性对照；二者不是同一博物馆场景的因果性能基线。许可见 `NOTICE.md`，录音逐项来源见 `vendor/tidewater/public/audio/CREDITS.md`。

这些是生态地貌展区与美术外形候选，岛屿允许不同时代的史前生物共处。巨木的设计不依据“整个恐龙时代均高氧”的假设。动物仍按淡水、海水与空中生境安置；其他海岸的现代鸟形与CC0鸟鸣仍是环境示意。具体古植物、动物物种、气候年代仍需随内容接入逐项核对。内陆水面反射仍受屏幕/有限高度场影响，独立河流焦散和海洋玩法尚未定义，桌面结果不代表移动设备的图形性能。
